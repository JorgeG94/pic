array_hash64_t

type, public :: array_hash64_t

A streaming 64-bit FNV-1a accumulator over array state.

A freshly declared array_hash64_t is already seeded with ARRAY_HASH64_OFFSET_BASIS, so no explicit initialisation call is needed. Feed it with update, read it with digest, and start over with reset.


Components

integer(kind=int64), private :: nbytes = 0_int64

Number of encoded bytes consumed so far. Fixed-width int64 so that hashing more than 2 GiB of state cannot overflow the counter in a default_int == int32 build.
integer(kind=int64), private :: state = ARRAY_HASH64_OFFSET_BASIS

Running hash. Fixed-width int64, because FNV-1a is defined modulo 2**64.

      !! A streaming 64-bit FNV-1a accumulator over array state.
      !!

      !! `ARRAY_HASH64_OFFSET_BASIS`, so no explicit initialisation call is
      !! needed. Feed it with `update`, read it with `digest`, and start over
      !! with `reset`.

         !! modulo 2**64.
      integer(int64) :: nbytes = 0_int64
