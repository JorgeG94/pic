public interface soa_hash_begin

Reset a hash accumulator and fold in a container’s identity.

Resolves on the accumulator’s type, so the same call site serves a 32-bit array_hash_t and a 64-bit array_hash64_t. Both feed the identical byte stream; only the digest width differs.
