public interface next_bernoulli_ppm

Return true with probability ppm in a million.

ppm is clamped to [0, PPM_ONE], so 0 never fires and 1000000 always does, and no value in between can be mistyped into an error. Parts per million rather than a real probability because this reaches simulation state: an incident either happened or it did not, and two runs must agree on which.
