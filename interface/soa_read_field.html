public interface soa_read_field

Read one field record back and check its length.

Usage: call soa_read_field(unit, name, values, n, swapped, err)

values is reallocated to exactly n elements. name appears in the error message so a mismatch names the offending field. swapped is the flag returned by soa_read_prologue.

Fails with ERROR_VALIDATION when the record holds a number of elements other than n, or when a logical record holds a code other than 0 or 1, and with ERROR_IO when the stream is truncated.
