public interface parse_int

Parse a string into an integer, reporting failures through error_t.

The accepted grammar is optional surrounding whitespace, an optional + or - sign and one or more decimal digits, with nothing else. An empty or blank string, a missing digit, any stray character (including trailing junk such as "12abc") and a value too large for the requested kind all set ERROR_PARSE and leave value at zero.

Specific procedures exist for int32 and int64, so an argument declared integer(default_int) resolves correctly in both the default and the USE_INT8 build.
